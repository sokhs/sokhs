## 🎯 Engineering Philosophy

I believe good software engineering is more than writing code.

I try to focus on:

**Readable Code**
Code should be easy for other engineers to understand.

**Maintainability**
Software should be designed so it can evolve without becoming difficult to change.

**Reliability**
Systems should handle failures gracefully.

**Security**
Security should be considered from the beginning of the design.

**Performance**
Understand where bottlenecks come from before optimizing.

**Continuous Learning**
Software engineering changes constantly, so learning never stops.
